How to Join PeakSMP

Free to join, no whitelist required. Connect on Java or Bedrock Edition, version 1.8.9 through the latest release.

Server IP
PeakSMP.net
Port (Bedrock)
19132
Java Bedrock
Java Edition
1
Open Minecraft: Java Edition
Launch the game and go to the main menu.
2
Go to Multiplayer
Select Multiplayer, then click Add Server.
3
Enter the server address
Type PeakSMP.net as the server address and save.
4
Join
Double-click the server to connect. You're in — no whitelist needed.
Bedrock Edition
1
Open Minecraft: Bedrock Edition
Available on Windows, mobile, and console versions of Minecraft.
2
Go to Servers
From the main menu, select Play, then the Servers tab, and scroll to Add Server.
3
Enter the server address and port
Set the server address to PeakSMP.net and the port to 19132, then save.
4
Join
Select the server to connect. You're in — no whitelist needed.
